# 🎲 Pokémon Random Team Generator

Um projeto pessoal para gerar **times aleatórios de Pokémon** e deixar minhas jogatinas nos jogos de Nintendo Switch mais desafiadoras e divertidas.

A ideia é evitar usar sempre os mesmos Pokémon e criar uma experiência diferente a cada nova campanha.

## 🎯 Objetivo

O projeto gera um time aleatório de Pokémon seguindo as regras definidas para cada jogo.

Cada time gerado pode ser utilizado para tentar **zerar o jogo utilizando apenas os Pokémon sorteados**.

## 🎮 Jogos

O projeto poderá ter suporte para diferentes jogos de Pokémon disponíveis no Nintendo Switch, como:

- Pokémon Let's Go, Pikachu! / Eevee!
- Pokémon Sword / Shield
- Pokémon Brilliant Diamond / Shining Pearl
- Pokémon Legends: Arceus
- Pokémon Scarlet / Violet

> A lista de jogos e as regras podem mudar conforme o desenvolvimento do projeto.

## ⚙️ Funcionalidades

- 🎲 Geração de times aleatórios
- 🐾 Seleção de Pokémon disponíveis no jogo
- 🚫 Evitar Pokémon duplicados no mesmo time
- 💾 Possibilidade de salvar times gerados
- 📋 Visualização dos Pokémon sorteados
- 🎮 Regras específicas para cada jogo

## 📌 Regras

As regras do sorteio podem variar de acordo com o jogo.

Alguns exemplos:

- O Pokémon precisa estar disponível no jogo.
- Não podem existir Pokémon repetidos no time.
- O time deve possuir até 6 Pokémon.
- Pokémon lendários/míticos podem ser excluídos do sorteio.
- O Pokémon sorteado será utilizado durante a campanha.

As regras ainda podem ser modificadas conforme novas ideias forem adicionadas ao projeto.
